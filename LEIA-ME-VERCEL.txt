Esta versão contém SOMENTE a oferta de R$ 67, sem botão Voltar e sem as páginas do aplicativo.

Rotas na Vercel:
/         — Oferta
/oferta   — Mesma oferta
/vsl.html — Player VTurb no iframe da oferta

Testar no VS Code:
1. Extraia o ZIP em uma pasta vazia.
2. Abra a pasta no VS Code (a raiz é onde está index.html).
3. Clique com botão direito em index.html e selecione Open with Live Server.
4. Abra o endereço fornecido pelo Live Server, como http://127.0.0.1:5500/index.html
5. Para testar /oferta localmente, abra /oferta/index.html (a Vercel usa /oferta sem index.html).

Publicar na Vercel:
1. Envie todos os arquivos extraídos para a RAIZ de um repositório GitHub.
2. Importe o repositório na Vercel.
3. Framework Preset: Other; Build Command: vazio; Output Directory: .
4. Publique e abra / ou /oferta.
